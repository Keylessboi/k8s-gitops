# Triage Labels

Five canonical triage roles. This table maps them to the label strings in this repo's issue tracker.

| Skill role | Label in tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer must evaluate |
| `needs-info` | `needs-info` | Waiting on reporter for details |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the matching label string from this table.
